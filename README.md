# Tres ejercicios Java MVC

Este repositorio contiene tres proyectos independientes de Java Swing, organizados en los paquetes `control`, `modelo` y `vista`.

## Proyectos

- `EjercicioMascotasMVC`: registro sencillo de mascotas de una veterinaria.
- `EjercicioEstudiantesMVC`: registro de notas de 1 a 20; desde 14 se muestra Aprobado.
- `EjercicioLibrosMVC`: catálogo que permite marcar libros como Disponible o Prestado.

Cada proyecto tiene su carpeta `datos` con el archivo `.txt` donde se guardan sus registros. El método `main` está en `src/control/Main.java`.

## Importar en Eclipse

1. Descarga el repositorio con **Code > Download ZIP** y descomprímelo.
2. En Eclipse elige **File > Import > Existing Projects into Workspace**.
3. Selecciona la carpeta descomprimida del repositorio y marca los tres proyectos.
4. Para ejecutar uno, abre su archivo `src/control/Main.java` y elige **Run As > Java Application**.
